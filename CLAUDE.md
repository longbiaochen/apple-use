# Apple Use For Claude

This repo retains local Apple Notes and Reminders tooling. Route:

- Apple Notes -> `apple-notes`
- Apple Reminders -> `apple-reminders`
- Apple Mail or any email task -> `apple-mail`, using Himalaya first and `macos-use` only for native Mail edge behavior

Do not use this repo's retired `apple_mail_*` tools, `fruitmail`, AppleScript helpers, direct Mail database access, or provider APIs. Read [docs/agent-contract.md](./docs/agent-contract.md) and the selected skill before acting.
